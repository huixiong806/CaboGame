# Hard 迭代实验结果（2026-10-05）

## 结论与晋升

Normal 保持 `3d6f668` 的默认决策，Easy 未改。Hard 新增仅使用公开历史的防循环保护，解决全员搜索自我对弈中真实发生的无限弃牌交换。V1 价值网络加普通宣告复核/门槛 0 的组合，分别在 2,048 场独立四人、2,048 场独立两人对照中建立了胜率与分差改善证据；通过显式本地模型环境变量可以试用，模型不随 Git 发布。单独网络贡献、对搜索型强对手的提升尚未建立证据。本次共完成 30 组、15,712 场配对实战评估，另有训练及预测测试比赛。

深度学习路线已落地为真实引擎比赛采集、深度整局价值网络、NumPy 与 CUDA 训练、Rust 推理、信息隔离检查和独立对局消融。这是 Monte Carlo 价值学习及近似策略迭代实验，还不是完整的端到端策略强化学习。

## 验收方法与限制

- 使用真实规则引擎，AI 输入限于 `PlayerView`，命令非法立即失败，无纠错回退；整场累计分比赛包含高牌双对与一次恰好 100 降为 50。
- 实战表通常为 4 人完整比赛；R26/R29/R30 是 2 人，R27 是 3 人。通常 1 名候选对其他席位的独立陪练，R23/R25 改为搜索型 Normal（32 轨迹、16 复核）。另一组用相同种子和相同候选座位替换为对照，每个种子轮换所有座位，每座位使用独立随机流。
- 统计独立单位是完整的种子块，不能把不同座位当成独立样本。表中的差值为候选减对照；胜率单位为百分点，分差越低越好；区间沿用评估器的配对块 95% 区间（小样本 t、大样本近似）。
- 默认评估使用 `budget_us=0` 和固定轨迹数，消除计时噪声。多任务同时运行的平均耗时只能作实验成本参考，不是实际 UI 延迟。尚未建立真人胜率、完整策略联盟以及 600ms 默认预算下的大样本棋力证据。
- 训练覆盖 2/3/4 人与随机公开累计分；不把随机残局样本数量当成从零分开始的实战场数。预测目标是当前采集策略的继续比赛结果，不是博弈论最优胜率。
- 开发候选很多，可能发生多重比较挑选偏差。只有独立验收可以支持晋升；R24 使用预先固定的更大独立样本，支持 V1 加宣告目标组合在本协议下改善，仍需区分对手、人数与预算条件。

R24 的最终复核预先固定 256 个独立块、2,048 场，以全新 seed 580000 起步；重验 V1 加普通宣告复核/门槛 0 对冻结 Normal，双方 128 轨迹、48 复核，显式关闭防循环以隔离战略变化。V1 权重冻结，结果不用于再挑模型。

R30 用新 seed 595000 起步、512 个独立两人块，只替换 V1/原价值公式；双方同为宣告复核、门槛 0、防循环及 128/48 预算。2,048 场的胜率差 +0.4 ± 3.1 个百分点、分差 -1.75 ± 2.78，不能确认网络本身的贡献。结合 R21，组合的显著提升不能称为深度学习单独带来的提升，也不能由不同种子测试的绝对胜率证明宣告调整单独的贡献。

历史复现说明：R1～R5、R11 在当时 Hard 临时启用根搜索时运行，最终配置默认关闭，复现须明确设置 `root_racing=true`。R6/R8 在行为证据的弃牌获取重放一致性修复前运行，仅作历史诊断；不当作最终代码的晋升证据。R1～R21 使用防循环保护加入前冻结的实验可执行文件。模型 V1/V2 的路径固定，没有在运行中的评估期间覆盖权重。

## 自我对弈停滞与数据完整性

首次全员学习搜索采集在 seed 530200、530272、530454、550238 达到十万步上限。seed 530200 用 2,000 步上限复现：两人将 5、7、12 在同一槽位与弃牌堆中反复轮换，没有摸牌、能力或宣告。失败批次的所有文件标记为 `.invalid.tsv`，未用于训练、验证或模型选择，不能只训练成功结束的比赛。

Hard 的新保护在公开事件连续两次重复完整单张弃牌交换循环后摸牌。相同历史检查覆盖两种根搜索，不读取未公开点数。四个原失败 seed 在原采集策略、同一 RNG 配置下全部在 2,000 步内完整结束，分别产生 10、16、11、11 个回合边界，没有非法命令。该修复不改变规则，也不是对所有可能循环的通用数学证明。

R22 使用 64 个独立块、4 座位、512 场完整比赛，对比同预算 Hard 保护开/关；这组对局的全部结算结果一致，胜率和分差差值均为 0，非法命令为 0。它支持保护未扰动这组普通对局，不证明所有局面的胜率永远相同。

采集器以后先写 `.incomplete`，整批成功才生成正式 TSV；保留超限失败 seed、公开事件尾部和合法玩家视图；输出 manifest 记录完整种子范围。训练器拒绝明确标记的失败/不完整文件，存在 manifest 时核查完整比赛覆盖。

修复后重新采集的三批全部结束，没有丢弃失败比赛：训练 1,200 场/7,989 行、验证 300 场/1,961 行、测试 600 场/3,975 行，均无非法命令或两千步超限。此次运行使用 manifest 功能加入前冻结的防循环采集器；在退出成功后另行核对精确 seed 范围、同场人数及赢家标签，并写本地 SHA256 manifest。

## 已通过的安全与回归检查

`cargo test --release --lib --tests`：38 个库测试、3 个 AI 集成测试、28 个规则引擎测试通过，5 个诊断默认忽略。最终整套检查在设置 `CABO_HARD_VALUE_MODEL` 的条件下再次通过。显式执行本地模型的推理/座位对称检查，以及隐藏底牌扰动后的完整搜索决策一致性检查，也全部通过。Normal 的冻结夹具仍为 458 次决策、FNV 值 `16368717308336445282`。

本地 V1 默认 Hard 预算检查覆盖 2/3/4 人的闲置与摸牌后 6 个合法局面：实测 175.8～464.5ms、1,278～8,192 条轨迹，所有命令可由真实引擎应用。这是时间和合法性检查，不是默认预算完整比赛的胜率验证。

候选行为推断通过真实引擎与紧凑模拟器的逐步重放检查。普通 Cabo 的最终响应复核，以及“宣告失败但整局价值较高、仍不能无视更好动作强制宣告”的反例均有回归测试。

Python 工具通过语法编译检查，本轮 planner 与采集器通过定向 rustfmt 检查。全仓 `cargo fmt --all -- --check` 仍会报告大量既有格式差异；没有为消除此类差异重排无关源码。

## 下一阶段判断

当前证据支持停止继续堆叠局部重置奖励、微调宣告阈值或只扩大累计分价值数据。这些路径的边际收益已很小或无法独立复现。

从输入与搜索结构推断，累计分网络主要重标定回合结算后的继续比赛概率，无法直接学习当前手牌判断、对手响应或多回合凑牌的行动先验。如果它只是让多个动作的概率同时更准确，而没有改变动作排序，就不会增加胜率。这是预测进步与棋力进步之间可能的瓶颈，尚不是单独通过消融证明的因果结论。

未来价值还依赖自身与对手的继续策略。当前网络不编码策略身份，而当前回合的对手 rollout 仍是快策略混合；训练与实际搜索/人类对手的分布可能不匹配。这是 R25 未建立收益的一个可能原因，后续需要更强的对手响应模型、包含历代策略与 Normal 的训练/验收对手池，而不是只扩大同类分数样本。

深度强化学习仍是合理的长期方向；更有价值的下一步是编码合法手牌知识、公共动作历史和候选动作，学习策略先验与当前回合价值，再与信息集搜索和包含历代策略的对手池结合。不能把多人部分可观察 Cabo 直接当成完全信息的 AlphaZero 问题，也不能把两人零和方法的保证推广到这里。需要继续以完整比赛、多策略对手和独立种子验收。
