# Hard 整局价值模型

`hard-value-v1.bin` 是默认 Hard 使用的预训练模型，随仓库分发。无需重新训练，也无需安装 Python、深度学习框架或 GPU 驱动。

| 项目 | 内容 |
|---|---|
| 用途 | 根据公开计分状态估计各座位赢下整局的概率 |
| 输入 | 玩家累计分、重置资格、人数、结束阈值与 Cabo 惩罚 |
| 参数 | 3,425 个 float32 |
| 文件大小 | 13,708 字节，约 13.4 KiB |
| 格式 | `CABOMV01`，Rust 原生推理 |
| SHA256 | `f41dedda1ab25df3b0f7692807724831a89dffdd9118fa05d55f8fb6ecd96fc8` |
| 许可 | 与项目一致，MIT |

模型由真实规则引擎生成的合成对局训练，输入不含未知手牌、牌堆次序或随机种子。网络对每位玩家共享编码器，并汇总全桌特征，输出整局胜率分布。

默认 Hard 将模型与整局收益导向的 Cabo 独立复核组合使用，并保留更高搜索预算和确定终局判定。自动加载会核对已验收模型的文件身份与格式。该组合针对默认结束阈值 100、惩罚 10；其他设置自动使用对应规则的搜索策略。

模型文件缺失时游戏仍可运行，Hard 使用搜索策略。自定义研究模型可用 `CABO_HARD_VALUE_MODEL` 指定路径；显式路径无效时会报错。设置为 `off` 可关闭模型。
